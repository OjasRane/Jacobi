# Constants

Jacobi also provides some constant values.

Table of constants

| Constant   | Type     | Description                                                                                    | Value                      |
|------------|----------|------------------------------------------------------------------------------------------------|----------------------------|
| `pi`       | `double` | $\pi$ is the ratio of circle's circumference to diameter                                       | `3.14159265358979323846`   |
| `e`        | `double` | Euler's number that is defined to be $\lim_{x\rightarrow\infty}\left({1+\frac{1}{x}}\right)^x$ | `2.718281828459045`        |
| `ln2`      | `double` | Natural logarithm of 2                                                                         | `0.6931471805599453094172` |
| `eps`      | `double` | A small value, used as tolerance. Short for epsilon($\epsilon$)                                | `1e-12`                    |
| `Infinity` | `double` | Infinity                                                                                       | $\infty$                   |
| `nan`      | `double` | Not a number                                                                                   | $\mathrm{NaN}$             |
